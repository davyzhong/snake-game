## v0.4.5 · 棋盘下方局内功能栏（2026-07-05）

### 🛒 购买体验重做

- 可购买功能从顶部弹窗移到棋盘下方，4 个功能一排显示，玩游戏时可以直接点击使用。
- 每个功能按钮会显示价格和“可买xN”，N 按当前糖豆余额实时计算。
- 未开局或游戏结束时不再允许购买限时功能，避免买了以后效果被浪费或玩家看不懂。
- 暂停时可以购买功能；磁铁和慢动作的限时效果会在暂停期间冻结。

### 🍬 功能调整

- 糖果磁铁从 8 秒延长到 20 秒。
- 顶部“功能”面板保留为任务入口，不再承担主要购买入口。

## v0.4.4 · 升级奖励、任务和小蛇详情（2026-07-05）

### 📈 升级系统第一版

- 每条小蛇继续独立积累经验，并新增 1-5 级奖励说明。

- 第一批任务：吃 5 个苹果、得到 100 分、坚持 30 秒。
- 完成任务会获得糖豆，并跟随当前玩家存档保存。

### 🧩 体验修复

- 30×30 棋盘下的初始演示苹果坐标全部收回棋盘范围内。
- 开局和护盾复位位置调整到棋盘中心区域。

## v0.3.0 · 阶段 1 视觉重做（2026-07-04）

### 🎨 视觉全面重做 —— 从"糖葫芦圆球"到"3D 果冻立体风"

**蛇身彻底重做**

- **顶部高光月牙 + 小亮点**，果冻质感
- **底部投影**，有"贴在地面"的重量感
- **头大尾细**：尾部几节半径渐缩，像真蛇

**蛇头大升级**

**苹果彻底重做**

- **径向渐变**（左上亮 → 右下暗）

- 金苹果带**发光环**、蓝苹果 ❄ 标识、紫苹果 ▽ 标识

**棋盘背景重做**
- **双色交替草地格**（棋盘式）
- 细网格线
- 配色由**主题驱动**

### ✨ 特效系统（新增）

- `state.effects` 队列驱动，`drawEffects()` 每帧渲染，过期自动清理
- 配套工具函数：`spawnEatEffect(cx, cy, appleType)`、`hexToRgb(hex)`

### 🌈 多主题切换系统（新增）

## v0.2.1 · 多玩家档案系统（2026-07-04）

### 👥 多玩家数据隔离

解决"和别人数据混在一起""怕换人玩就丢进度"的诉求。

**数据层升级**
- 新增存档 key `snake-players`，存一棵完整的玩家树：
  ```
  { version, activeId, players: {
      "p1": { name, avatar, best, roundHistory, progress, lastSnakeId, themeId, createdAt },
      "p2": { ... }
  }}
  ```

- `state.best / roundHistory / progress` 始终是"当前激活玩家"的运行时镜像

**老存档自动迁移**
- 检测到旧的 `snake-best-score` 等 key → 自动迁移成玩家1（默认名"玩家1"、头像🦊）
- 旧 key 保留不删作为兜底

### 🎭 玩家管理 UI

- 顶部加「玩家切换器」：一排圆形 emoji 头像，当前玩家绿圈高亮
- **单击**头像 = 切到该玩家（数据瞬间切换）
- **双击**头像 = 编辑（改名/换头像/删除）
- 绿色 **＋** 按钮新建玩家（选 emoji + 输入名字，最多 8 字）
- 8 个预设头像：🦊🐰🐯🐼🐸🦁🐨🐵
- **上限 4 个**，达到后 ＋ 自动禁用

### ✂️ 玩家 CRUD 函数

新增：`loadPlayers / migrateLegacyPlayers / newDefaultPlayer / savePlayers / applyPlayerToState / createPlayer / switchPlayer / deletePlayer / renamePlayer / nextPlayerId / saveLastSnake`

`chooseSnake` 增加 `saveLastSnake()` 调用，记住每玩家上次选的蛇。

### 🔒 安全设计

- 删除带 `confirm` 二次确认
- 删的是当前玩家 → 自动切到剩余的第一个
- 全删光了 → 自动重建一个默认玩家，不会崩

## v0.2.0 · 阶段 0 地基重构（2026-07-04）

### 🏗️ 代码分层重构

把散乱的全局变量收敛成结构化状态，引入固定步长游戏循环和明确的游戏阶段。**此阶段外观与玩法完全保持不变**，为后续阶段铺路。

**新增 7 层架构**
| 层 | 职责 | 关键产物 |
|---|---|---|
| **CONFIG** | 静态配置集中 | `CONFIG` 对象（苹果/蛇/等级阈值/存档 key/主题） |
| **STATE** | 单一状态对象 | `state` 替代原来 14 个散落的 `let` 变量 |
| **DOM** | 节点缓存 | `els` 对象 |
| **LOGIC** | 纯游戏逻辑 | `step / newGame / endGame / placeApples / applyAppleEffect` 等 |
| **RENDER** | 纯绘制 | `render / drawBackground / drawSnakeBody / drawApple` |
| **INPUT** | 键盘+触控 | 统一事件处理 |
| **LOOP** | 固定步长循环 | `requestAnimationFrame + accumulator` |

### 🔄 游戏循环改造

- 原来：`setInterval(step, tickMs)` —— 速度变化时抖动，无法支持连续动画
- 现在：`requestAnimationFrame + accumulator` 固定步长循环
  - 逻辑按固定 tick 步长推进保证稳定
  - 渲染每帧执行为阶段 1 的连续动画铺路
  - 切后台积压过久会自动限幅（防一次性大跳）

### 🎯 阶段状态机

引入 `phase` 字段（`menu | playing | paused | gameover`），替代原来零散的 `running / paused / message.hidden` 组合判断。后续阶段加新界面都挂到 `phase` 上。

### 📦 存档兼容

- `localStorage` 三个旧 key（`snake-best-score / snake-round-history / snake-progress`）此时保持不变
- 老存档无缝继承

### 🐛 修复

- 修复了一个 JS 提升顺序 bug：派生常量（`CELL_SIZE` 等）依赖 `canvas`，挪到 DOM 缓存之后初始化

### 📝 相关文件

- 新增 `snake-game-v1-backup.html`：原始版备份（1279 行，已知良好状态）

## v0.1.0 · 初始版本（2026-07-04）

### 🎮 原始游戏功能

经典贪吃蛇的趣味加强版，单文件 HTML5 网页游戏。

**核心玩法**
- 40×40 网格棋盘
- 方向键（电脑）或方向按钮（手机）控制蛇移动
- 撞墙或撞自己即游戏结束
- 空格键暂停/继续

**6 种可选小蛇角色**（各有差异化属性）

| 蛇 | 速度 | 得分倍率 | 特点 |
|---|---|---|---|
| 稳稳蛇 | 380ms | 1.0× | 速度很慢，最容易控制 |
| 苹果蛇 | 330ms | 1.5× | 吃苹果得分更多 |
| 闪闪蛇 | 260ms | 1.2× | 跑得快，适合挑战 |
| 蓝莓蛇 | 320ms | 1.1× | 速度中等，分数也稳定 |
| 星星蛇 | 300ms | 1.8× | 得分最高，但要小心 |
| 彩虹蛇 | 285ms | 1.3× | 速度轻快，身体会变色 |

**4 种特殊苹果**
- 红苹果（+10 分，70% 概率）
- 金苹果（+30 分，12% 概率）
- 蓝苹果（+10 分，减速 5 秒，10% 概率）
- 紫苹果（+6 分，变短 2 节，8% 概率）

**养成升级系统**
- 每条蛇有独立经验/等级（共 5 级，阈值 0/100/250/500/900）
- 升级后分数倍率提升（每级 +0.15）
- 进度用 `localStorage` 持久化

**记录系统**
- 最高分、最近 8 局历史记录（含蛇名、分数、时间）

**视觉（原始版）**
- 草绿色卡通配色
- 蛇为圆球串（头身几乎没区别）—— 后续被阶段1 重做
- 苹果为简陋双圆球 —— 后续被阶段1 重做
- 桌面端（左右侧栏 + 中间棋盘）和移动端（垂直堆叠 + 触控按钮）响应式适配

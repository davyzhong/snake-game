## ⏳ 后续方向

### 阶段 2 · 障碍物 + 主动技能

**障碍物系统**
- 棋盘散布**石头、树桩、水池**，撞上即死
- 与苹果/蛇初始位置避让，保证可玩
- `state.obstacles` 已预留，`isCellBlocked()` 已包含障碍检测
- 新增 `drawObstacles()` 渲染层
- 关卡式或随机布局

**主动技能系统**（每蛇一个，带冷却）

| 蛇 | 技能 | 效果 | 冷却 |
|---|---|---|---|
| 稳稳蛇 | 稳护盾 | 3 秒撞墙/撞自己不死 | 15s |
| 苹果蛇 | 苹果雨 | 瞬间刷出 6 个苹果 | 20s |
| 闪闪蛇 | 冲刺 | 短时高速穿 3 格 | 12s |
| 蓝莓蛇 | 磁铁 | 5 秒吸引附近苹果 | 18s |
| 星星蛇 | 无敌 | 3 秒撞不死 | 25s |
| 彩虹蛇 | 穿墙 | 一次从边界穿越 | 20s |

- `state.skill` 已预留 `{ cooldownUntil, activeUntil }`
- 桌面按 `Q` 触发，配套技能按钮和冷却环
- 冷却用环形进度可视化

**实施要点**
- CONFIG 加 `skills` 配置
- LOGIC 加 `activateSkill()` / `updateSkillCooldown()`
- RENDER 加 `drawSkillButton()` / 冷却环
- INPUT 加 Q 键 + 移动端按钮

### 阶段 3 · 连击 Combo + 关卡递进（部分完成）

**连击系统**
- 短时间（如 3 秒）内连续吃 → Combo ×2 / ×3 / ×5...
- 超时或死亡中断
- 屏幕显示连击数大字 + 倍率
- 与苹果分数、蛇倍率叠加
- ✅ 已实现：2.6 秒连吃窗口、连击倍率、闪闪蛇连击奖励和连击收藏。

**关卡/难度递进**
- 按分数推进关卡：速度↑、苹果↓、障碍↑
- 关卡切换有过场提示
- 新增 `state.level`（运行时关卡，区别于蛇等级）

### 阶段 4 · 任务/成就 + 每日挑战（部分完成）

**任务系统**

**每日挑战**
- ✅ 已实现按日期重置的每日目标并保存到玩家档案。

## 📅 优先级与依赖

```
阶段 0 ✅ → 阶段 1 ✅ → 玩法增强 ✅ → 阶段 2 ⏳ → 阶段 5 ⏳
                               (连击/任务/商店)  (障碍+技能)  (扩展商店)
```

- 阶段 2 依赖阶段 1 的渲染层（障碍物要画）
- 阶段 3 的连击会用到阶段 1 的特效系统
- 阶段 4/5 依赖玩家档案系统（已完成）

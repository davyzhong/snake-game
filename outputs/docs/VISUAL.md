# 视觉系统

游戏采用桌面优先的果园奖励竞技场风格：图像和角色必须完整、清晰、对齐，棋盘装饰不和可吃物混淆。

## 棋盘与对齐

- Canvas 为 1300×1300，棋盘为 26×26，因此每格 50px。
- 蛇、苹果、棋盘道具和目标提示都由 `cellCenter()` 定位；格子范围由 `cellRect()` 定义。
- `visualScale` 当前为：蛇身 `0.42`、蛇头 `1.04`、食物 `0.44`、星光 `0.85`。视觉主体需收在所属格内，避免误判路线。
- 四角宝石只在棋盘外框，互动区域内不放不能吃的装饰图。

## 素材规则

- 侧栏小蛇使用完整正方形角色图，`object-fit`/背景尺寸保持比例，不可横向或纵向压扁。
- 角色图片必须完整展示，文字信息放到独立描述区域，不能再在长卡片中二次裁切方形图。
- 道具、食物、宝箱优先使用 `assets/` 中生成的透明 PNG；不要用 emoji 代替游戏主视觉。
- 运行时只预加载 Canvas 真正需要的图集；CSS 背景由浏览器按需加载。

## Canvas 绘制顺序

```text
缓存棋盘底图
  -> 食物目标提示
  -> 食物、礼盒、首领和棋盘道具
  -> 蛇
  -> 粒子与高对比奖励文字
```

棋盘的草地格、纹理和细网格是静态层。`getBoardBackgroundCache()` 会按主题/尺寸缓存该层，避免每帧重复生成 26×26 格纹。主题切换时缓存自动失效并重绘。

## 动效与可读性

- 吃食物会产生粒子、飘字和对应颜色的反馈。
- 奖励文字使用不透明底牌和描边，不能直接叠在复杂背景上。
- 限时道具、礼盒、首领和任务提示使用各自的图集和色彩，图标、名称、触发动作必须一一对应。
- 尊重桌面画面空间，不以移动端压缩为设计目标。
